# Volna — музыка онлайн без загрузки на телефон

Мобильное приложение для прослушивания музыки в потоке, как в стриминговых сервисах:
треки ничего не занимают в памяти телефона, всё играет напрямую из интернета.
Работает **без VPN и без регистрации**, бесплатно.

## Что умеет

- **Главная** — популярное за неделю по жанрам, трендовые плейлисты, недавно прослушанное.
- **Поиск** — треки, исполнители, плейлисты и альбомы; подборки по жанрам.
- **Радио** — ~50 000 интернет-радиостанций со всего мира (по жанрам, странам, поиск по названию).
- **Медиатека** — любимые треки и станции (♡), сохранённые плейлисты, история.
- **Плеер** — очередь, «играть следующим», перемешивание, повтор, перемотка,
  управление с экрана блокировки и наушников, продолжение с того же места после перезапуска.

## Откуда музыка

| Источник | Что это |
|---|---|
| [Audius](https://audius.co) | Открытая бесплатная стриминговая сеть: сотни тысяч треков от независимых артистов и лейблов, публичный API без ключей |
| [Radio Browser](https://www.radio-browser.info) | Открытый каталог интернет-радио (в т.ч. российские станции с популярной музыкой) |

Приложение хранит на телефоне только список избранного и историю — без аудиофайлов.

### Почему не Spotify

Spotify ушёл из России, и подключить его «напрямую» не получится:
официальный API Spotify разрешает проигрывать полные треки только владельцам Premium
и только через установленное приложение Spotify. Оплатить Premium из России нельзя,
а обходить ограничения Spotify через свой сервер запрещено их правилами (аккаунт могут
заблокировать). Поэтому здесь используются открытые легальные источники, которые
работают без VPN.

## Как установить на телефон

### Вариант 1 — Android APK

1. Откройте вкладку **Actions** в репозитории → дождитесь зелёной сборки **Android APK**.
2. Перейдите в **Releases** → «Последняя сборка» → скачайте `Volna.apk` на телефон.
3. Откройте файл и разрешите установку из неизвестных источников.

Новые версии ставятся поверх старой — избранное сохраняется.

### Вариант 2 — веб-приложение (Android и iPhone)

1. В репозитории: **Settings → Pages → Source: GitHub Actions** (один раз).
   Веб-версия публикуется из ветки `main` (или запуском вручную: Actions → Web app → Run workflow).
2. После сборки **Web app (GitHub Pages)** появится ссылка вида
   `https://<логин>.github.io/TungTungVolna/`.
3. Откройте её на телефоне:
   - Android (Chrome): меню ⋮ → **Добавить на главный экран / Установить приложение**;
   - iPhone (Safari): **Поделиться → На экран «Домой»**.

> GitHub Pages для приватных репозиториев доступен только на платных тарифах GitHub.
> Если репозиторий приватный — используйте APK или сделайте репозиторий публичным.

В веб-версии недоступны радиостанции, вещающие по незащищённому `http://`
(браузер их блокирует); в APK работают все станции.

## Разработка

```bash
npm install
npm start               # http://localhost:8080
```

Код приложения — в `www/` (чистые HTML/CSS/JS, без сборщика):

- `js/api.js` — работа с Audius и Radio Browser;
- `js/player.js` — плеер, очередь, экран блокировки;
- `js/app.js` — экраны и навигация;
- `js/store.js` — избранное и история (localStorage).

Сборка APK локально (нужен Android Studio):

```bash
npx cap add android
npx @capacitor/assets generate --android
npx cap sync android
npx cap open android
```
