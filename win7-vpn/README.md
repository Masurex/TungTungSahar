# SaharVPN — VPN-клиент для Windows 7 (32 бит)

Простой клиент в духе Happ / NekoBox: VLESS + Reality (а также VLESS TLS/WS/gRPC/XHTTP, Trojan, Shadowsocks).
Работает через ядро **Xray-core** (официальная сборка для Windows 7) в режиме **системного прокси** —
этого достаточно для браузеров (Chrome, Яндекс.Браузер, Firefox, Opera, Edge, IE), в том числе для YouTube.

## Что нужно

* Windows 7 SP1 (32 или 64 бит).
* .NET Framework 4.5 или новее. Лучше всего 4.8:
  https://dotnet.microsoft.com/download/dotnet-framework/net48
  (если программа не запускается совсем — почти наверняка не хватает именно его).
* Права администратора **не нужны**.

## Установка

1. Скачайте `SaharVPN-win7-32.zip` со страницы релиза `win7-vpn` в репозитории.
2. Распакуйте **всю папку** куда угодно, например на Рабочий стол или в `C:\SaharVPN`.
   Внутри должна быть папка `core` с файлом `xray.exe` — без неё программа не подключится.
3. Запустите `SaharVPN.exe`.

## Как подключиться (Gemera VPN)

1. В Telegram-боте Gemera VPN скопируйте **ключ** (`vless://…`) или **ссылку подписки** (`https://…`).
   Если бот предлагает выбрать приложение — выбирайте v2rayN / «Другое» / «Скопировать ключ».
2. В SaharVPN нажмите **«Вставить ключ из буфера»**.
3. Выберите сервер в списке и нажмите **«Подключить»**.
4. Откройте браузер — YouTube должен работать. Под статусом будет написано
   «Интернет через VPN работает, задержка … мс».

Ссылки вида `happ://crypt…` зашифрованы под Happ и в других программах не открываются —
попросите в боте обычную ссылку или ключ.

## Полезное

* **Российские сайты напрямую** — банки, Госуслуги, Яндекс, VK идут без VPN (включено по умолчанию).
* **Запускать вместе с Windows** + **Подключаться автоматически** — VPN включится сам после входа в систему.
* Двойной клик по серверу — подключиться к нему. Выбор другого сервера во время работы — мгновенное переключение.
* «Пинг» — проверка, отвечают ли серверы. «Проверить связь» — реальная проверка интернета через VPN.
* Свернуть окно — программа уйдёт в значок возле часов (серый — выключено, зелёный — подключено).
  Закрыть крестиком — VPN выключится, настройки прокси вернутся как были.

## Если что-то не работает

* **Подписка не загружается** — на старой Windows 7 может не работать HTTPS (TLS 1.2).
  Установите обновления Windows (SP1, KB3140245) или вставьте ключ `vless://…` напрямую.
* **«Ядро Xray не запустилось»** — посмотрите журнал внизу окна. Частая причина — порты 10808/10809
  заняты другой VPN-программой (закройте её) или антивирус удалил `core\xray.exe` (добавьте папку в исключения).
* **Сайты не открываются после аварийного закрытия** — просто запустите SaharVPN снова и закройте его:
  настройки прокси восстановятся. Или: Панель управления → Свойства браузера → Подключения →
  Настройка сети → снять галочку «Использовать прокси-сервер».
* Программы, которые не используют системный прокси (игры, некоторые мессенджеры), идут без VPN.
  Для Telegram можно указать прокси вручную: SOCKS5, `127.0.0.1`, порт `10808`.

## Для разработчиков

Исходники — в `win7-vpn/src` (C#, WinForms, .NET Framework 4.5, x86).
Сборка: `dotnet build win7-vpn/SaharVPN.csproj -c Release` (работает и в Linux).
GitHub Actions (`.github/workflows/win7-vpn.yml`) собирает exe, докладывает `Xray-win7-32.zip`
из релизов XTLS/Xray-core и публикует архив в релиз `win7-vpn`.
Настройки и список серверов хранятся в папке `data` рядом с программой.
